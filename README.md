## 🧩 Опис функціональних модулів

### **EG8010 — генерація PWM / моделювання синуса**
- Формує PWM-сигнали для управління ключами MOSFET згідно з синусоїдальною кривою.
- Параметри (амплітуда, фаза) налаштовуються через STM32.

### **STM32F103 — керуючий контролер**
- Зчитує дані: напруга, струм, потужність з PZEM-004T.  
- Керує зарядом акумулятора — вмикає/вимикає зарядний пристрій.  
- Керує перемиканням між мережею та інвертором.  
- Відображає інформацію на дисплеї ST7789.  
- Реагує на аварійні ситуації: перегрів, перевантаження, низька напруга тощо.

### **HCPL-3120 — оптичні драйвери для MOSFET**
- Оптодрайвер високої швидкості для управління затворами MOSFET.  
- Гальванічна ізоляція між логікою (STM32 / EG8010) і силовою частиною.  
- Забезпечує точне і швидке перемикання ключів.

### **PZEM-004T — енергомоніторинг**
- Вимірює: **напрягу**, **струм**, **активну потужність**, **енергію**.  
- Передає дані через UART до STM32.  
- Дані використовуються для контролю роботи інвертора й заряду.

### **ST7789 — дисплей**
- Виводить:  
  - Напругу батареї  
  - Струм  
  - Потужність  
  - Стан заряду  
  - Аварійні повідомлення  
  - Інші параметри системи
